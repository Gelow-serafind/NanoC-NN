# ABS_001: 官方 Abs QDQ/int8 同量化数值精度

## 验证目标

验证 ONNX 官方 `Abs` 在 Q/DQ int8 边界下可以生成可运行的 C 推理路径，
并与原始 ONNX Runtime 输出保持一致。

## 来源

内部探索 / 图谱驱动 TDD。`Abs` 是 ONNX 官方基础 unary 算子，适合补齐
低算力端常见的简单逐元素算子覆盖面。

## ONNX Schema 归属

| 字段 | 内容 |
|------|------|
| domain | `ai.onnx` |
| op_type | `Abs` |
| opset_range | `11+` |
| schema_form | `static QDQ/int8 tensor, same input/output quantization` |
| lowering | `generated_c_abs_s8` |
| backend | `cmsis-nn` |

## 网络结构

```text
Input(1,8)
  -> QuantizeLinear
  -> DequantizeLinear
  -> Abs
  -> QuantizeLinear
  -> DequantizeLinear
  -> Output(1,8)
```

## 输入

- **张量形状**: `[1, 8]`
- **ONNX 边界数据类型**: float32
- **运行期核心数据类型**: int8

## 算子参数

| 算子 | 参数 |
|------|------|
| Abs | 无属性 |

## 量化设计

| 张量 | scale | zero_point | 说明 |
|------|-------|------------|------|
| input/input_q | 0.05 | 0 | float 输入进入 int8 量化域 |
| output/output_q | 0.05 | 0 | 与输入一致，避免重标定干扰 Abs 语义 |

## 预期结果

- **codegen status**: `ok`
- 生成物通过 C99 smoke compile
- ONNX Runtime 与生成 C 输出完全一致

## 数值验收

- **是否需要**: `yes`
- **数据集**: `tdd/fixtures/datasets/abs_qdq_smoke/dataset.json`
- **参考路径**: 原始 ONNX Runtime
- **通过阈值**: top1 一致率 1.0，最大绝对误差 0.0，饱和率不超过 0.25

## 边界/风险

- 当前只确认静态 shape、per-tensor int8、输入输出同 scale/zero_point 的形态。
- `-128` 的 int8 绝对值不可表示，生成 C 路径需要饱和到 `127`。
- 不同输入输出量化参数、动态 shape、高维张量和与其他算子融合的情况后续继续独立覆盖。
