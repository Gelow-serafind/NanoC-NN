# ERF_001: 官方 Erf QDQ/int8 静态张量

## 验证目标

验证 `Erf` 对静态 QDQ/int8 tensor 生成 C99 逐元素误差函数路径，输出与 ONNX Runtime 数值一致。

## 来源

内部探索：ONNX 官方图谱 unary 数学扩展，`erf` 为 C99 `math.h` 标准函数，适合 correctness baseline。

## ONNX Schema 归属

| 字段 | 值 |
|------|----|
| domain | `ai.onnx` |
| op_type | `Erf` |
| opset_range | `9+` |
| schema_form | `static QDQ/int8 tensor` |
| lowering | `generated_c_erf_s8` |
| backend | `cmsis-nn` |

## 网络结构

```text
Input -> Q/DQ -> Erf -> Q/DQ Output
```

## 输入

- **张量形状**: `[1, 8]`
- **数据类型**: int8 QDQ 数据路径，输入域受控于 `[-1.5, 1.5]`

## 算子参数

| 算子 | 参数 |
|------|------|
| Erf | 无参数，逐元素 `erf(x)` |

## 量化设计

| 张量 | scale | zero_point | 说明 |
|------|-------|------------|------|
| input | `0.05` | `0` | 外部输入量化 |
| output | `0.05` | `0` | 输出重新量化 |

## 预期结果

- **codegen status**: `ok`
- **若 ok**: 编译通过、运行不崩溃
- **关键验证点**: 生成 C 中存在逐元素 `erff` 调用

## 数值验收

- **是否需要**: `yes`
- **数据集**: `tdd/fixtures/datasets/erf_qdq_smoke/dataset.json`
- **参考路径**: 原始 ONNX Runtime
- **通过阈值**: top1 一致率 `1.0`，最大绝对误差 `0.05`，饱和率不超过 `0.25`

## 边界/风险

`erff` 与 ONNX Runtime 的 float erf 存在 1-ULP 级差异可能，允许最大绝对误差 `0.05`（1 个 int8 单位）以容忍量化取整边界抖动；输入域受控于 erf 显著变化区间。
