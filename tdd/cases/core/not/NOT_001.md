# NOT_001: 官方 Not bool 逻辑中间张量驱动 Where

## 验证目标

验证 `Not` 可以对单个 bool 中间张量（由比较类算子产生）做逻辑取反，输出 bool condition 并作为 `Where` 输入参与后续 int8 数据选择。

## 来源

内部探索：bool 中间张量子图能力扩展，`Not` 是单输入 bool 算子，构成阈值反向选择类图结构。

## ONNX Schema 归属

| 字段 | 值 |
|------|----|
| domain | `ai.onnx` |
| op_type | `Not` |
| opset_range | `7+` |
| schema_form | `single bool intermediate tensor (compare output), bool output consumed by Where` |
| lowering | `generated_c_not_bool` |
| backend | `cmsis-nn` |

## 网络结构

```text
Input -> Q/DQ
Static QDQ rhs_a + input_dq -> Greater -> not.a_cond (bool)
not.a_cond -> Not -> not.combined (bool)
Where(not.combined, input_dq, static zero) -> Q/DQ Output
```

## 输入

- **张量形状**: `[1, 8]`
- **数据类型**: int8 QDQ 数据路径，`Not` 输入输出均为内部 bool 中间张量

## 算子参数

| 算子 | 参数 |
|------|------|
| Greater | 产条件 `input > rhs_a` |
| Not | 对条件取反 |
| Where | bool condition 选择 input 或 zero |

## 量化设计

| 张量 | scale | zero_point | 说明 |
|------|-------|------------|------|
| input | `0.05` | `0` | 比较左输入 |
| rhs_a | `0.05` | `0` | 比较常量 |
| zero | `0.05` | `0` | Where else 分支 |
| output | `0.05` | `0` | 输出重新量化 |

- **关键验证点**: `Not` 的 bool 输出应能被 `Where` 正确消费
