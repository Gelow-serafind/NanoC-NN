# ADD_001: 官方 Add QDQ/int8 同形状常量分支数值精度

## 验证目标

验证 ONNX 官方 `Add` 的 QDQ/int8 同形状常量分支可以 lower 到 `arm_elementwise_add_s8`。

## 来源

内部探索 / 图谱驱动 TDD。当前已有 observed `QLinearAdd`，本用例把官方 `Add` 纳入图谱。

## ONNX Schema 归属

| 字段 | 内容 |
|------|------|
| domain | `ai.onnx` |
| op_type | `Add` |
| opset_range | `11+` |
| schema_form | `same-shape QDQ/int8 tensors, second input may be constant` |
| lowering | `cmsis_elementwise_add_s8` |
| backend | `cmsis-nn` |

## 网络结构

```text
Input(1,8) -> Q -> DQ ----.
                         Add -> Q -> DQ -> Output(1,8)
Const(1,8) -> DQ --------'
```

## 输入

- **张量形状**: `[1, 8]`
- **ONNX 边界数据类型**: float32
- **运行期核心数据类型**: int8

## 算子参数

| 算子 | 参数 |
|------|------|
| Add | numpy broadcast 语义，本用例为同形状 |

## 量化设计

| 张量 | scale | zero_point | 说明 |
|------|-------|------------|------|
| input/input_q | 0.05 | 0 | 动态输入 |
| add.const.q | 0.05 | 0 | 常量分支 |
| output/output_q | 0.05 | 0 | 输出量化 |

## 预期结果

- **codegen status**: `ok`
- 生成物包含 `arm_elementwise_add_s8`
- ONNX Runtime 与生成 C 输出误差在阈值内

## 数值验收

- **是否需要**: `yes`
- **数据集**: `tdd/fixtures/datasets/add_qdq_smoke/dataset.json`
- **通过阈值**: top1 一致率 1.0，最大绝对误差 0.08，饱和率不超过 0.25

## 边界/风险

暂不声明 broadcast、双动态输入、不同 rank 输入。
