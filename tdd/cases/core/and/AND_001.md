# AND_001: 官方 And bool 逻辑中间张量驱动 Where

## 验证目标

验证 `And` 可以对两个 bool 中间张量（由比较类算子产生）做逻辑与，输出 bool condition 并作为 `Where` 输入参与后续 int8 数据选择。这是阈值窗口类图结构的典型形态。

## 来源

内部探索：bool 中间张量子图能力扩展，`And` 消费 compare 输出，构成 `Greater -> Less -> And -> Where` 阈值区间选择。

## ONNX Schema 归属

| 字段 | 值 |
|------|----|
| domain | `ai.onnx` |
| op_type | `And` |
| opset_range | `7+` |
| schema_form | `two bool intermediate tensors (compare outputs), bool output consumed by Where` |
| lowering | `generated_c_and_bool` |
| backend | `cmsis-nn` |

## 网络结构

```text
Input -> Q/DQ
Static QDQ rhs_a + input_dq -> Greater -> and.a_cond (bool)
Static QDQ rhs_b + input_dq -> Less -> and.b_cond (bool)
and.a_cond, and.b_cond -> And -> and.combined (bool)
Where(and.combined, input_dq, static zero) -> Q/DQ Output
```

## 输入

- **张量形状**: `[1, 8]`
- **数据类型**: int8 QDQ 数据路径，`And` 输入输出均为内部 bool 中间张量

## 算子参数

| 算子 | 参数 |
|------|------|
| Greater | 产左条件 `input > rhs_a` |
| Less | 产右条件 `input < rhs_b` |
| And | `left AND right` 组合为窗口条件 |
| Where | bool condition 选择 input 或 zero |

## 量化设计

| 张量 | scale | zero_point | 说明 |
|------|-------|------------|------|
| input | `0.05` | `0` | 两个比较的左输入 |
| rhs_a | `0.05` | `0` | 下界比较常量 |
| rhs_b | `0.05` | `0` | 上界比较常量 |
| zero | `0.05` | `0` | Where else 分支 |
| output | `0.05` | `0` | 输出重新量化 |
