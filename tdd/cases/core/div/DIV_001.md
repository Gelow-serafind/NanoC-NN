# DIV_001: 官方 Div QDQ/int8 同形状非零常量分支数值精度

## 验证目标

验证 ONNX 官方 `Div` 的 QDQ/int8 同形状非零常量分支可以生成真实 C 推理路径。

## 来源

内部探索 / 图谱驱动 TDD。该用例补齐逐元素二元算术中的除法形态，并显式限制分母非零。

## ONNX Schema 归属

| 字段 | 内容 |
|------|------|
| domain | `ai.onnx` |
| op_type | `Div` |
| opset_range | `11+` |
| schema_form | `same-shape QDQ/int8 tensors, non-zero second input may be constant` |
| lowering | `generated_c_div_s8` |
| backend | `cmsis-nn` |

## 网络结构

```text
Input(1,8) -> Q -> DQ ----.
                         Div -> Q -> DQ -> Output(1,8)
Const(1,8) -> DQ --------'
```

## 输入

- **张量形状**: `[1, 8]`
- **ONNX 边界数据类型**: float32
- **运行期核心数据类型**: int8

## 算子参数

| 算子 | 参数 |
|------|------|
| Div | numpy broadcast 语义，本用例为同形状，常量分支反量化后非零 |

## 量化设计

| 张量 | scale | zero_point | 说明 |
|------|-------|------------|------|
| input/input_q | 0.05 | 0 | 动态输入 |
| div.const.q | 0.05 | 0 | 非零常量分支 |
| output/output_q | 0.05 | 0 | 输出量化 |

## 预期结果

- **codegen status**: `ok`
- 生成物包含 `generated_c_div_s8` 路径或等价逐元素 C 代码
- ONNX Runtime 与生成 C 输出误差在阈值内

## 数值验收

- **是否需要**: `yes`
- **数据集**: `tdd/fixtures/datasets/div_qdq_smoke/dataset.json`
- **参考路径**: 原始 ONNX Runtime
- **通过阈值**: top1 一致率 1.0，最大绝对误差 0.08，饱和率不超过 0.25

## 边界/风险

暂不声明 broadcast、双动态输入、动态零分母处理。生成代码仍需防御近零分母。
