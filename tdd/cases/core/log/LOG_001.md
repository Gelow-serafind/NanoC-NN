# LOG_001: 官方 Log QDQ/int8 正输入域数值精度

## 验证目标

验证 ONNX 官方 `Log` 在正输入 QDQ/int8 数据路径上可生成可执行 C。

## 来源

内部探索：人工构造最小官方 ONNX schema 用例。

## ONNX Schema 归属

- `ai.onnx/Log`
- opset: 11+
- support id: `ONNX_LOG_QDQ_INT8`

## 网络结构

`input -> QuantizeLinear -> DequantizeLinear -> Log -> QuantizeLinear -> DequantizeLinear -> output`

## 输入

- shape: `[1, 8]`
- dtype: float32 API 输入，内部 QDQ/int8
- value domain: 严格正数

## 算子参数

无属性。

## 量化设计

- input/output scale: `0.05`
- input/output zero_point: `0`

## 预期结果

**codegen status**: `ok`

生成 `generated_c_log_s8` C99 correctness baseline。

## 数值验收

- dataset: `log_qdq_smoke`
- max_abs_error: `0.06`
- saturation ratio: `<= 0.25`

## 边界/风险

当前不覆盖非正输入；生成 C 会做防御性保护，避免 MCU 上出现无定义行为。
