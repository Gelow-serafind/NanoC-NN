# OR_001: 官方 Or bool 逻辑中间张量驱动 Where

## 验证目标

验证 `Or` 可以对两个 bool 中间张量（由比较类算子产生）做逻辑或，输出 bool condition 并作为 `Where` 输入参与后续 int8 数据选择。

## 来源

内部探索：bool 中间张量子图能力扩展，`Or` 消费 compare 输出，构成阈值选择类图结构。

## ONNX Schema 归属

| 字段 | 值 |
|------|----|
| domain | `ai.onnx` |
| op_type | `Or` |
| opset_range | `7+` |
| schema_form | `two bool intermediate tensors (compare outputs), bool output consumed by Where` |
| lowering | `generated_c_or_bool` |
| backend | `cmsis-nn` |

## 网络结构

```text
Input -> Q/DQ
Static QDQ rhs_a + input_dq -> Less -> or.a_cond (bool)
Static QDQ rhs_b + input_dq -> Less -> or.b_cond (bool)
or.a_cond, or.b_cond -> Or -> or.combined (bool)
Where(or.combined, input_dq, static zero) -> Q/DQ Output
```

## 输入

- **张量形状**: `[1, 8]`
- **数据类型**: int8 QDQ 数据路径，`Or` 输入输出均为内部 bool 中间张量

## 算子参数

| 算子 | 参数 |
|------|------|
| Less | 产左条件 `input < rhs_a` |
| Less | 产右条件 `input < rhs_b` |
| Or | `left OR right` 组合条件 |
| Where | bool condition 选择 input 或 zero |

## 量化设计

| 张量 | scale | zero_point | 说明 |
|------|-------|------------|------|
| input | `0.05` | `0` | 两个比较的左输入 |
| rhs_a | `0.05` | `0` | 左比较常量 |
| rhs_b | `0.05` | `0` | 右比较常量 |
| zero | `0.05` | `0` | Where else 分支 |
| output | `0.05` | `0` | 输出重新量化 |

## 预期结果

- **codegen status**: `ok`

- **关键验证点**: `Or` 的 bool 输出应能被 `Where` 正确消费
