# PAD_001: 官方 Pad QDQ/int8 rank4 constant mode 数值顺序

## 验证目标

验证 ONNX 官方 `Pad` 的静态 rank4 QDQ/int8 constant mode 可以生成真实 C copy 推理路径。

## 来源

内部探索 / 图谱驱动 TDD。该用例覆盖真实模型中常见的边界补零或补常量行为。

## ONNX Schema 归属

| 字段 | 内容 |
|------|------|
| domain | `ai.onnx` |
| op_type | `Pad` |
| opset_range | `11+` |
| schema_form | `static rank=4 QDQ/int8 tensor, constant mode, constant pads initializer` |
| lowering | `generated_c_pad_s8` |
| backend | `cmsis-nn` |

## 网络结构

```text
Input(1,1,2,3) -> Q -> DQ -> Pad -> Q -> DQ -> Output(1,1,4,5)
```

## 输入

- **张量形状**: `[1, 1, 2, 3]`
- **ONNX 边界数据类型**: float32
- **运行期核心数据类型**: int8

## 算子参数

| 算子 | 参数 |
|------|------|
| Pad | `mode=constant`, `pads=[0,0,1,1,0,0,1,1]` |

## 量化设计

| 张量 | scale | zero_point | 说明 |
|------|-------|------------|------|
| input/input_q | 0.05 | 0 | 动态输入 |
| output/output_q | 0.05 | 0 | 与输入同量化，pad 常量为 0 |

## 预期结果

- **codegen status**: `ok`
- 生成物包含 `generated_c_pad_s8` 路径或等价 copy C 代码
- ONNX Runtime 与生成 C 输出逐元素一致

## 数值验收

- **是否需要**: `yes`
- **数据集**: `tdd/fixtures/datasets/pad_qdq_smoke/dataset.json`
- **参考路径**: 原始 ONNX Runtime
- **通过阈值**: top1 一致率 1.0，最大绝对误差 0.0，饱和率不超过 0.25

## 边界/风险

暂不声明 reflect/edge mode、动态 pads、不同输入输出量化或负 padding。
