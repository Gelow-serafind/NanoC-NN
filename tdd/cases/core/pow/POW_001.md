# POW_001: 官方 Pow QDQ/int8 同形状有限输入域数值精度

## 验证目标

验证 ONNX 官方 `Pow` 在有限输入域 QDQ/int8 双输入路径上可生成可执行 C。

## 来源

内部探索：人工构造最小官方 ONNX schema 用例。

## ONNX Schema 归属

- `ai.onnx/Pow`
- opset: 11+
- support id: `ONNX_POW_QDQ_INT8`

## 网络结构

`input -> Q/DQ` 与 `constant exponent -> DQ` 进入 `Pow`，再 `Q/DQ -> output`

## 输入

- shape: `[1, 8]`
- dtype: float32 API 输入，内部 QDQ/int8
- value domain: 非负底数，小范围正指数

## 算子参数

无属性。

## 量化设计

- input/output scale: `0.05`
- input/output zero_point: `0`

## 预期结果

**codegen status**: `ok`

生成 `generated_c_pow_s8` C99 correctness baseline。

## 数值验收

- dataset: `pow_qdq_smoke`
- max_abs_error: `0.08`
- saturation ratio: `<= 0.25`

## 边界/风险

当前不覆盖负底数、非整数指数、NaN/Inf 和广播。
