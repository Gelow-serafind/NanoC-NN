# MIN_001: 官方 Min QDQ/int8 同形状双输入数值精度

## 验证目标

验证 ONNX 官方 `Min` 在同形状 QDQ/int8 双输入路径上可生成可执行 C。

## 来源

内部探索：人工构造最小官方 ONNX schema 用例。

## ONNX Schema 归属

- `ai.onnx/Min`
- opset: 11+
- support id: `ONNX_MIN_QDQ_INT8`

## 网络结构

`input -> Q/DQ` 与 `constant -> DQ` 进入 `Min`，再 `Q/DQ -> output`

## 输入

- shape: `[1, 8]`
- dtype: float32 API 输入，内部 QDQ/int8

## 算子参数

无属性。

## 量化设计

- input/output scale: `0.05`
- input/output zero_point: `0`

## 预期结果

**codegen status**: `ok`

生成 `generated_c_min_s8` C99 correctness baseline。

## 数值验收

- dataset: `min_qdq_smoke`
- max_abs_error: `0.0`
- saturation ratio: `<= 0.25`

## 边界/风险

当前只保护同形状双输入，第二输入为量化常量。广播和多输入留到后续。
