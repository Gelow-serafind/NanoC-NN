# NEG_003: ArgMin 非 int8 index 输出边界

## 验证目标

验证 `ArgMin`（输出 int64 index）被正确拒绝为 `unsupported`，因为当前生成框架与数值验收仅支持 int8 模型外部 ABI。

## 来源

内部探索：100% 计划 W0 边界，`ArgMin` 输出 index 张量（int64），与 int8 数据路径不兼容。

## 网络结构

```text
Input(FLOAT32) -> Q/DQ int8 -> ArgMin(axis=1) -> Output(int64)
```

## 输入

- **张量形状**: `[1, 4]`
- **数据类型**: int8 QDQ 输入，输出为 int64 index

## 算子参数

| 算子 | 参数 |
|------|------|
| ArgMax/ArgMin | axis=1、keepdims=1，输出 int64 index |

## 量化设计

输入为 int8 QDQ，输出为非 int8 index 张量（本边界核心）。

## 预期结果

- **codegen status**: `unsupported`
- **pipeline 退出码**: 非零
- **边界原因**: 模型外部输出为非 int8 张量；`ArgMin` 支持需扩展非 int8 外部 ABI 与 numeric runner，留待后续框架迭代。

## 数值验收

- **是否需要**: `no`（拒绝边界，仅断言正确拒绝）

## 边界/风险

一旦框架支持非 int8 外部输出，本用例应改判 `ok` 并补充 index 数值验收。
