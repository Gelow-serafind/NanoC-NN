# NET_001: SqueezeNet 1.0 int8 真实网络导入评估

## 验证目标

验证 TDD 能导入一个 MNIST 之外的真实 int8 ONNX 小型图像分类网络，生成包含真实 CMSIS-NN 调用的 C 推理工程，并在统一 smoke 数据集上完成 ONNX Runtime 与生成 C 的并行推理一致性验收。

## 来源

内部探索 / 真实模型导入。模型来自 ONNX Model Zoo 的 SqueezeNet 1.0 int8 镜像，用于扩展低算力视觉分类网络覆盖面。该模型比 MNIST 更接近真实 fire module CNN，包含多分支 `Concat`、大量 `QLinearConv` 和 `QLinearGlobalAveragePool`，适合作为新的完整网络导入测试。

## 网络结构

```text
Float Input(1,3,224,224)
  -> QuantizeLinear
  -> QLinearConv / MaxPool
  -> repeated fire modules:
       squeeze QLinearConv
       expand1x1 QLinearConv
       expand3x3 QLinearConv
       DequantizeLinear + Concat + QuantizeLinear
  -> QLinearConv
  -> QLinearGlobalAveragePool
  -> DequantizeLinear
  -> Softmax
  -> Float Output(1,1000,1,1)
```

## 输入

- **张量形状**: `[1, 3, 224, 224]`（NCHW: batch=1, RGB, H=224, W=224）
- **ONNX 边界数据类型**: float32
- **运行期核心数据类型**: int8 / QLinear

## 算子参数

| 算子 | 参数 |
|------|------|
| QLinearConv x26 | 1x1 / 3x3 卷积，per-channel weight scale，bias int32 |
| MaxPool x3 | SqueezeNet 下采样池化 |
| Concat x8 | fire module expand 分支拼接 |
| QLinearGlobalAveragePool x1 | 分类头全局平均池化 |
| Softmax x1 | 1000 类 ImageNet 输出 |

## 量化设计

| 张量 | scale | zero_point | 说明 |
|------|-------|-----------|------|
| data_0 | initializer | initializer | float 输入经 QuantizeLinear 进入 int8/uint8 量化域 |
| QLinearConv weights | per-channel initializer | initializer | 来自模型原始量化参数 |
| fire module concat | initializer | initializer | 分支 Dequantize + Concat + Quantize 的量化边界 |
| pool10_1 | initializer | initializer | QLinearGlobalAveragePool 输出量化参数 |

## 预期结果

- **codegen status**: `ok`
- **若 ok**: 生成物必须包含真实 CMSIS-NN 调用并通过 C99 smoke compile/run
- **关键验证点**:
  - 外部 ONNX fixture 能被复制到 `tdd/work/models/networks/NET_001.onnx`
  - converter 能解析模型基本结构、输入输出、initializer 和 op mapping
  - 生成代码包含 `arm_convolve_wrapper_s8`、`arm_max_pool_s8`、`arm_concatenation_s8_z`、`arm_avgpool_s8` 和 `arm_softmax_s8`
  - 生成 C 与原始 ONNX 在固定 smoke probes 上保持分类输出一致，且输出饱和率受控
  - SRAM/Flash 超限属于目标平台预算门禁，后续应以 `oversize` 单独表达，不作为本用例 blocked 的核心原因
  - 不允许生成 fallback stub、空运行路径或不可编译 C

## 数值验收

- **是否需要**: `yes`
- **数据集**: `tdd/fixtures/datasets/net_001_squeezenet_smoke/`
- **参考路径**: 原始 SqueezeNet ONNX Runtime 输出
- **执行路径**: 生成 C 的 CMSIS-NN int8 `nanoc_model_run()` 路径
- **通过阈值**:
  - `top1_min_match_ratio = 1.0`
  - `top1_tie_margin = 0.02`
  - `max_abs_error = 0.21`
  - `max_saturation_ratio = 0.75`
- **当前结果**: `top1=4/4`，饱和率 `0.00`，最大绝对误差 `0.2`

说明：该数据集是固定、可复现的 ImageNet 输入形状 smoke probes，不是 ImageNet 分类准确率数据集。`midgray` 是低置信 near-tie 样本，ONNX top1 与 C top1 在 ONNX 概率上的 margin 为 `0.0174`，低于 `top1_tie_margin=0.02`，因此计入可接受一致；其余样本 exact top1 一致。

## 边界/风险

- 该模型输入尺寸和激活较大，若面向 256K SRAM 等具体 MCU 预算，后续应由平台预算检查返回 `oversize`。
- 图中存在 `DequantizeLinear -> Concat -> QuantizeLinear` 的不同量化分支拼接，当前由 `CONCAT_002` 独立保护。
- `QLinearGlobalAveragePool` 由 `AVGPOOL_001` 独立保护。
- 末端 float output `Softmax` 当前由 `SOFTMAX_002` 独立保护，C 侧输出为 int8 softmax 概率；1000 类低概率输出会存在 int8 步进量导致的排序抖动，因此用 near-tie margin 保护低置信样本。
- 本用例通过代表完整 SqueezeNet 结构可生成、可编译、可运行，并在 smoke probes 上完成 ONNX-vs-C 一致性验收；尚不代表 ImageNet 真实标签分类准确率已经验证。
