# NET_004: KWS DS-CNN-style int8 网络导入评估

## 验证目标

引入面向 keyword spotting 的 DS-CNN-style int8 fixture，覆盖 Cortex-M 常见的音频特征输入、depthwise separable convolution、pooling 和 FC 分类头。

## 来源

内部探索。TDD 生成 fixture。结构参考 TinyML/KWS 中常见 DS-CNN 形态，使用确定性随机权重生成；该用例用于暴露生成器拓扑和算子缺口，不用于声明语音识别准确率。

## 网络结构

```text
Float Input(1, 1, 49, 10)
  -> Q/DQ
  -> Conv2d stem
  -> ReLU
  -> depthwise Conv2d(group=8)
  -> ReLU
  -> pointwise Conv2d
  -> ReLU
  -> MaxPool
  -> Flatten
  -> Gemm
  -> Float logits(1, 4)
```

## 输入

- **张量形状**: `float32[1, 1, 49, 10]`
- **数据类型**: float32 边界输入，内部 Q/DQ int8
- **输出**: `float32[1, 4]`，可代表 silence / unknown / yes / no 四类 logits

## 算子参数

| 算子 | 参数 |
|------|------|
| Conv2d stem | out_channels=8, kernel=3x3, pads=1 |
| depthwise Conv2d | group=8, kernel=3x3, pads=1 |
| pointwise Conv2d | out_channels=16, kernel=1x1 |
| MaxPool | kernel=2x2, stride=2 |
| Flatten/Gemm | 1920 -> 4 |

## 量化设计

| 张量 | scale | zero_point | 说明 |
|------|-------|------------|------|
| input | 0.04 | 0 | 频谱输入 Q/DQ |
| hidden activations | 0.05/0.06 | 0 | DS-CNN block 中间张量 |
| weights | 0.02 | 0 | 确定性随机 int8 权重 |
| logits | 0.05 | 0 | 输出反量化 |

## 预期结果

- **codegen status**: `ok`
- **关键验证点**：
  - 生成代码必须包含 `arm_convolve_wrapper_s8`、`arm_depthwise_conv_wrapper_s8`、`arm_max_pool_s8` 和 `arm_fully_connected_s8`。
  - depthwise `Conv(group=in_channels)` 必须被显式识别并进入真实运行路径。
  - C99 smoke compile/run 必须通过；当前不声明 KWS 语音识别准确率。

## 数值验收

当前不启用数值验收。未来若训练并固化真实 KWS 权重，应加入音频特征 smoke 数据集并对比 ONNX-vs-C logits/top1。

## 边界/风险

- 当前 fixture 使用确定性随机权重，只验证结构生成。
- depthwise separable conv block 仍需要独立数值用例。
- 频谱输入布局 NCHW/NHWC 后续需要明确策略。
