# NET_003: SSD-MobileNet int8 目标检测网络导入评估

## 验证目标

导入真实 SSD-MobileNet int8 ONNX，覆盖嵌入式视觉检测网络常见的多输出 head、box decode、动态 shape 和后处理结构。

## 来源

内部探索。ONNX Model Zoo / Hugging Face `onnxmodelzoo/ssd_mobilenet_v1_12-int8`。

## 网络结构

```text
Uint8 Input(N, H, W, 3)
  -> QuantizeLinear / QLinearConv backbone
  -> detection heads
  -> Decode / reshape / concat / loop-style postprocess
  -> detection_boxes, detection_classes, detection_scores, num_detections
```

## 输入

- **张量形状**: `uint8[N, H, W, 3]`，NHWC，空间维度在模型中以动态符号表示
- **数据类型**: uint8 输入，检测输出为 float
- **输出**: detection boxes/classes/scores/count，多输出动态维度

## 算子参数

| 算子 | 参数 |
|------|------|
| QLinearConv x47 | SSD-MobileNet backbone 和检测 head |
| Reshape/Transpose/Concat | 检测 head 张量重排与拼接 |
| Loop x2 | 后处理动态控制流 |
| Slice/Squeeze/Unsqueeze/Gather/Shape | 动态 shape 与 box decode |
| Sigmoid/Exp/Mul/Add/Sub | 检测框和分数后处理 |

## 量化设计

| 张量 | scale | zero_point | 说明 |
|------|-------|------------|------|
| inputs | initializer | initializer | uint8 NHWC 输入 |
| QLinearConv weights | initializer | initializer | 真实模型量化参数 |
| detection heads | mixed | mixed | 量化与 float 后处理交错 |
| outputs | float | n/a | 多输出检测结果 |

## 预期结果

- **codegen status**: `unsupported`
- **关键验证点**：
  - 多输出检测模型必须稳定拒绝，不能生成单输出分类路径。
  - `Loop`、动态 shape、box decode 后处理不属于当前 M7 代码生成闭环。
  - NHWC 输入和动态检测输出必须在报告中体现，而不是被静默折叠。

## 数值验收

当前不启用数值验收。未来只有在明确检测后处理策略后，才可加入小图像 smoke 数据集和框级误差阈值。

## 边界/风险

- 多输出模型的 blocked/unsupported 规则用例。
- `Reshape`/`Transpose`/`Concat` 检测 head 最小拓扑用例。
- 动态 shape 和 `Loop` 明确拒绝用例。
