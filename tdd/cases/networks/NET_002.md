# NET_002: MobileNetV2 int8/QLinear 图像分类网络导入评估

## 验证目标

导入真实 MobileNetV2 int8/QLinear ONNX，验证移动端图像分类网络在当前生成器中的结构生成能力。

## 来源

内部探索。ONNX Model Zoo / Hugging Face `onnxmodelzoo/mobilenetv2-12-int8`。

## 网络结构

```text
Float Input(batch, 3, 224, 224)
  -> QuantizeLinear
  -> QLinearConv / QLinearAdd blocks
  -> QLinearGlobalAveragePool
  -> Shape / Gather / Unsqueeze / Concat / Reshape
  -> QLinearMatMul
  -> DequantizeLinear
  -> Float Output(batch, 1000)
```

## 输入

- **张量形状**: `float32[batch_size, 3, 224, 224]`
- **数据类型**: float32 边界输入，运行期核心为 QLinear int8/uint8
- **输出**: `float32[batch_size, 1000]`

## 算子参数

| 算子 | 参数 |
|------|------|
| QLinearConv x52 | 1x1 / 3x3 移动端 CNN 卷积块 |
| QLinearAdd x11 | residual/add 融合路径 |
| QLinearGlobalAveragePool x1 | 分类头全局池化 |
| QLinearMatMul x1 | 1000 类分类头 |
| Shape/Gather/Unsqueeze/Concat/Reshape | 动态 batch 输出 reshape |

## 量化设计

| 张量 | scale | zero_point | 说明 |
|------|-------|------------|------|
| input | initializer | initializer | float 输入进入 QLinear 域 |
| QLinearConv weights | initializer/per-channel | initializer | 来自真实模型 |
| QLinearAdd tensors | initializer | initializer | residual 路径量化参数 |
| output | initializer | initializer | 末端反量化到 float 输出 |

## 预期结果

- **codegen status**: `ok`
- **关键验证点**：
  - 生成代码必须包含 `arm_convolve_wrapper_s8`、`arm_depthwise_conv_wrapper_s8`、`arm_elementwise_add_s8`、`arm_avgpool_s8` 和 `arm_fully_connected_per_channel_s8`。
  - shape-only `Shape/Gather/Unsqueeze/Concat/Reshape` 必须折叠为生成期逻辑。
  - C99 smoke compile/run 必须通过；当前不代表 ImageNet 数值正确。

## 数值验收

当前不启用数值验收。后续必须补充 ImageNet 风格 smoke 数据集并执行 ONNX-vs-C 输出对比，才能宣称 MobileNetV2 端到端数值正确。

## 边界/风险

- 当前仅完成结构生成验收，数值正确性尚未进入回归。
- MobileNetV2 的 SRAM 估算超过常见小 MCU，应由显式目标预算返回 `oversize`。
- 动态 batch 固定策略需要继续由独立最小用例保护。
