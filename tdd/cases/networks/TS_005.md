# TS_005: STWIN vowel IMU CNN

## 验证目标

验证 STWIN 6 通道 IMU vowel CNN 可生成 C99 float reference 推理代码，并与 ONNX Runtime 输出保持一致。

## 来源

内部探索：来自 STM32/STWIN 传感器手势识别场景，用于覆盖小型 Conv/Pool/GAP/FC/Softmax 完整网络。

## 网络结构

```text
Input → Conv → Relu → MaxPool → Conv → Relu → MaxPool → GlobalAveragePool → Flatten → Gemm → Softmax
```

## 输入

- **张量形状**: `[1, 6, 20, 20]`
- **数据类型**: float32 normalized IMU image

## 算子参数

| 算子 | 参数 |
|------|------|
| Conv | 3x3 SAME padding |
| MaxPool | 2x2 stride 2 |
| GlobalAveragePool | spatial average |
| Gemm | classifier head |
| Softmax | axis 1 |

## 量化设计

| 张量 | scale | zero_point | 说明 |
|------|-------|-----------|------|
| input | n/a | n/a | 原始模型为 float32 |
| weight | n/a | n/a | float32 initializer |
| output | n/a | n/a | float32 probability |

## 预期结果

- **codegen status**: `ok`
- **若 ok**: 编译通过、运行不崩溃
- **关键验证点**: `nanoc_model_run_float()` 输出 top1 与 ONNX Runtime 一致。

## 数值验收

- **是否需要**: `yes`
- **数据集**: `tdd/fixtures/datasets/timeseries_stwin_vowel_smoke/dataset.json`
- **参考路径**: 原始 ONNX Runtime
- **通过阈值**: top1 一致率 100%，最大绝对误差不超过 `1e-4`

## 边界/风险

当前数据集是固定 IMU image probe，不是真实 vowel 采集准确率集。该用例重点保护 float Conv/Pool/GAP/Softmax reference C 链路。
