# NET_005: Tiny signal jump int8 时序分类网络导入评估

## 验证目标

将项目已有 `example-2-detect-signal-jump` 升级为 TDD 真实网络 fixture，覆盖低算力工业信号/IMU/电流窗口分类场景。

## 来源

内部探索。`NanoC-NN-ONNX-Examples/example-2-detect-signal-jump/outputs/onnx/signal_jump.int8.onnx`。

## 网络结构

```text
Float Input(1, 1, 10)
  -> Q/DQ
  -> Conv1d
  -> ReLU
  -> Conv1d
  -> ReLU
  -> Flatten
  -> Gemm
  -> Float logits(1, 3)
```

## 输入

- **张量形状**: `float32[1, 1, 10]`
- **数据类型**: float32 边界输入，内部 Q/DQ int8
- **输出**: `float32[1, 3]`，no_jump / up_jump / down_jump logits

## 算子参数

| 算子 | 参数 |
|------|------|
| Conv1d x2 | kernel=2, channels 1->8->8 |
| Relu x2 | 激活 |
| Flatten | 8x8 -> 64 |
| Gemm | 64 -> 3 |

## 量化设计

| 张量 | scale | zero_point | 说明 |
|------|-------|------------|------|
| signal_window | initializer | initializer | 输入 Q/DQ |
| Conv weights | initializer | initializer | 示例训练导出量化参数 |
| logits | initializer | initializer | 输出 float logits |
