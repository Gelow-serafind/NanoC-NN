# TS_004: MET hybrid activity model

## 验证目标

验证双输入 MET activity hybrid ONNX 可生成 C99 float reference 推理代码，并与 ONNX Runtime 输出保持一致。

## 来源

内部探索：来自 wearable/smartphone 活动强度识别场景，用于覆盖多输入、MatMul、Conv1d 形态、广播 Add/Mul、Concat 和 Softmax。

## 网络结构

```text
Feature Input → MLP branch
Raw IMU Input → Unsqueeze/Transpose → Conv → BN-as-Mul/Add → Conv → GAP branch
Branches → Concat → MLP → Softmax
```

## 输入

- **张量形状**: `feat_input=[1, 36]`, `raw_input=[1, 150, 8]`
- **数据类型**: float32

## 算子参数

| 算子 | 参数 |
|------|------|
| MatMul/Add | dense branches |
| Conv | 1D Conv expressed as 2D Conv |
| Mul/Add | folded batch-norm arithmetic |
| Concat | axis 1 |
| Softmax | axis -1 |

## 量化设计

| 张量 | scale | zero_point | 说明 |
|------|-------|-----------|------|
| input | n/a | n/a | 原始模型为 float32 |
| weight | n/a | n/a | float32 initializer |
| output | n/a | n/a | float32 probability |

## 预期结果

- **codegen status**: `ok`
- **若 ok**: 编译通过、运行不崩溃
- **关键验证点**: `nanoc_model_run_float()` 支持多输入并保持 top1 与 ONNX Runtime 一致。

## 数值验收

- **是否需要**: `yes`
- **数据集**: `tdd/fixtures/datasets/timeseries_met_hybrid_smoke/dataset.json`
- **参考路径**: 原始 ONNX Runtime
- **通过阈值**: top1 一致率 100%，最大绝对误差不超过 `1e-4`

## 边界/风险

当前数据集是模型输入空间 smoke probe，不是真实 WISDM/MotionSense/UCI-HAR 准确率集。该用例重点保护多输入和广播拓扑。
