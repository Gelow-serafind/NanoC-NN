# TS_002: KWS DS-CNN PTQ INT8 Q/DQ

## 验证目标

验证真实 keyword spotting DS-CNN PTQ INT8 Q/DQ ONNX 可生成 C99 reference 推理代码，并保持 ONNX Q/DQ 语义。

## 来源

内部探索：来自低算力语音关键词检测场景，用于覆盖 Q/DQ Conv、depthwise Conv、GlobalAveragePool 和 Gemm 组合网络。

## 网络结构

```text
Float Input → Q/DQ → Conv/Relu blocks → GlobalAveragePool → Flatten → Gemm → Q/DQ Output
```

## 输入

- **张量形状**: `[1, 1, 40, 97]`
- **数据类型**: float32 log-mel feature

## 算子参数

| 算子 | 参数 |
|------|------|
| Conv | standard and depthwise Conv |
| GlobalAveragePool | spatial average |
| Gemm | classifier head |
| QuantizeLinear/DequantizeLinear | scalar and per-channel Q/DQ |

## 量化设计

| 张量 | scale | zero_point | 说明 |
|------|-------|-----------|------|
| input | from ONNX initializer | from ONNX initializer | Q/DQ 输入边界 |
| weight | per-tensor/per-channel | int8 zero point | Q/DQ 权重 |
| output | from ONNX initializer | from ONNX initializer | Q/DQ 输出边界 |

## 预期结果

- **codegen status**: `ok`
- **若 ok**: 编译通过、运行不崩溃
- **关键验证点**: `nanoc_model_run_float()` 按 ONNX Q/DQ 语义执行，top1 与 ONNX Runtime 一致。
