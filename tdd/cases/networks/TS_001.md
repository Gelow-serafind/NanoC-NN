# TS_001: CWRU bearing vibration MLP

## 验证目标

验证真实 CWRU bearing vibration MLP 可生成 C99 float reference 推理代码，并与原始 ONNX Runtime 输出保持一致。

## 来源

内部探索：来自时域/传感器真实 ONNX 网络扩展，用于覆盖工业振动健康/故障二分类场景。

## 网络结构

```text
Input → Flatten → Gemm → Relu → Gemm → Relu → Gemm → Output
```

## 输入

- **张量形状**: `[1, 1, 1, 32]`
- **数据类型**: float32

## 算子参数

| 算子 | 参数 |
|------|------|
| Gemm | `transB=1`, bias enabled |
| Relu | standard ReLU |

## 量化设计

| 张量 | scale | zero_point | 说明 |
|------|-------|-----------|------|
| input | n/a | n/a | 原始模型为 float32 |
| weight | n/a | n/a | float32 initializer |
| output | n/a | n/a | float32 logits |

## 预期结果

- **codegen status**: `ok`
- **若 ok**: 编译通过、运行不崩溃
- **关键验证点**: `nanoc_model_run_float()` 输出 top1 与 ONNX Runtime 一致。

## 数值验收

- **是否需要**: `yes`
- **数据集**: `tdd/fixtures/datasets/timeseries_cwru_bearing_smoke/dataset.json`
- **参考路径**: 原始 ONNX Runtime
- **通过阈值**: top1 一致率 100%，最大绝对误差不超过 `1e-4`

## 边界/风险

该用例验证 float reference C 路径，不声明 CMSIS-NN int8 kernel 支持。后续若要部署到纯 int8 CMSIS-NN，需要另行量化该模型。
