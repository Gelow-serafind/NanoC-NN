# NET_006: EfficientNet-Lite4 int8 小型图像分类网络导入评估

## 验证目标

导入 EfficientNet-Lite4 int8 ONNX，覆盖 NHWC 输入、MBConv 风格 QLinear 图、`QLinearAveragePool`、`QLinearMatMul` 和末端 float softmax。

## 来源

内部探索。ONNX Model Zoo / Hugging Face `onnxmodelzoo/efficientnet-lite4-11-int8`。

## 网络结构

```text
Float Input(1, 224, 224, 3)
  -> Transpose
  -> QuantizeLinear
  -> QLinearConv / QLinearAdd blocks
  -> QLinearAveragePool
  -> Squeeze
  -> QLinearMatMul
  -> DequantizeLinear
  -> Softmax
  -> Float Output(1, 1000)
```

## 输入

- **张量形状**: `float32[1, 224, 224, 3]`，NHWC
- **数据类型**: float32 边界输入，内部 QLinear int8/uint8
- **输出**: `float32[1, 1000]`

## 算子参数

| 算子 | 参数 |
|------|------|
| QLinearConv x91 | EfficientNet-Lite MBConv 风格卷积块 |
| QLinearAdd x24 | residual/add 路径 |
| QLinearAveragePool x1 | 分类头池化 |
| QLinearMatMul x1 | 1000 类分类头 |
| Transpose/Squeeze/Softmax | 输入布局转换和输出处理 |

## 量化设计

| 张量 | scale | zero_point | 说明 |
|------|-------|------------|------|
| images:0 | initializer | initializer | NHWC float 输入进入 QLinear 域 |
| QLinearConv weights | initializer/per-channel | initializer | 真实模型量化参数 |
| QLinearAveragePool | initializer | initializer | 量化池化边界 |
| Softmax:0 | float | n/a | 末端 float 输出 |

## 预期结果

- **codegen status**: `unsupported`
- **关键验证点**：
  - NHWC 输入和内部布局转换必须显式处理或阻塞。
  - `QLinearAveragePool`、`Squeeze`、`QLinearMatMul` 不能被误判为已支持。
  - 大型图像分类网络的 SRAM/Flash 预算不作为本用例主判据；预算应在显式目标平台参数中返回 `oversize`。

## 数值验收

当前不启用数值验收。若未来升级为 `ok`，必须补充可复现图像 smoke 数据集并对比 ONNX-vs-C。

## 边界/风险

- `QLinearAveragePool` 最小结构用例。
- `Squeeze`/`Reshape` layout 最小用例。
- NHWC 输入到 CMSIS-NN NHWC 内部布局策略用例。
